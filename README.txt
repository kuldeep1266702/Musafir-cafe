# Musafir Café — cinematic photo website

Open `index.html` in a modern browser.

Included:
- 7 uploaded photographs
- uploaded Musafir Café MP3 as the soundtrack
- Bollywood/café-inspired warm palette, marquee ticker, film grain, vinyl animation and scroll reveals
- responsive mobile layout

Note: browsers generally block autoplay with sound, so the soundtrack starts when the visitor taps “Play Musafir Café”.
